# Windows Domain and SMB File Server Lab

An educational Windows Server lab covering domain services, address assignment, shared folders, access groups, and client-side permission checks.

## Lab scope

- Installed and configured Active Directory Domain Services and DNS.
- Configured DHCP for virtual clients.
- Created domain users and security groups.
- Published SMB shares and assigned access based on group membership.
- Compared allowed and denied access from client accounts.
- Created a hidden share and checked read-only access.

## Environment

- Windows Server 2012 R2
- Windows client virtual machines
- Virtual network lab

## Limitations

This is a legacy educational lab, not a current deployment guide. Windows Server 2012 R2 is out of support. The walkthrough uses sample names and settings from an isolated virtual environment; do not expose this configuration to a real network. Any example credentials in the historical notes have been replaced with placeholders.
