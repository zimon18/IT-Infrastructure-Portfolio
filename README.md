# IT Infrastructure Portfolio

Hands-on learning projects in Linux services, Windows Server, networking and systems administration. The repository documents lab setups, configuration choices and troubleshooting evidence from virtual environments.

> These are educational lab projects. They are not production deployment guides. Some labs use legacy operating systems and software; see each project page for its scope and limitations.

## Projects

| Project | What it covers | Environment |
|---|---|---|
| [BIND DNS on Ubuntu Server](PL%20DNS%20BIND%20w%20Ubuntu%20Server%2018.04%20LTS/README-EN.md) | Static addressing, BIND9 forward and reverse zones, DNS validation, and client troubleshooting | Ubuntu Server 18.04, VirtualBox |
| [Windows domain file server](PL%20Serwer%20plik%C3%B3w%20SMB%20w%20W2012R2/README-EN.md) | Active Directory, DNS, DHCP, SMB shares, security groups, permissions, and client validation | Windows Server 2012 R2, virtual lab |
| [School network design](network-design/README.md) | A structured cabling and logical network proposal for five computer labs, including VLANs, addressing, equipment, and cost estimate | Cisco Packet Tracer and written design |

## How I work

I document the goal, the lab topology, configuration steps, checks, and the problems encountered. These projects show foundational practice with network services and infrastructure administration; they do not represent production administration experience.
